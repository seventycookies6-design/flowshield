Basalt design rethink, October 2026

Three directions for issue #368, each shown on the same five screens with the same sample data, plus Today at rest in the light theme. Every image is a 1280×860 render of the HTML file beside it. Rationale, hierarchy changes, new tokens and the recommendation are in README.md.

A · Dial

A 60-minute timer face with precise ticks replaces the empty ring; every setting sits in one control column beside it.

B · Ledger

Quiet editorial typography: no cards and no sidebar. A top bar, one reading column, hairline rules and very large tabular numerals. The next sprint is a sentence you edit; History opens with a sentence, not four stat boxes.

C · Causeway

Material and structure: a Windows 11 shell (Mica backdrop with a basalt-grain fallback, one content slab, settings cards) and the Causeway mark doing real work. Its lit tops are the shield level, large on Today; History uses hexagon cells and column-topped bars.
