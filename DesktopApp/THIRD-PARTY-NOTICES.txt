Fonts and icons

Basalt draws its text in Segoe UI Variable (Segoe UI on Windows 10) and its
icons in Segoe Fluent Icons (Segoe MDL2 Assets on Windows 10). These are
Windows' own system fonts: Basalt uses the copies Windows already has and
includes no font files of its own.
